# KeyCritter presentation downloads

- **KeyCritter-Copy-Board.zip**: a PowerPoint with 13 pages of individually selectable guide characters, speech bubbles, editable text boxes and page numbers.
- **KeyCritter-Slide-Elements.zip**: the complete editable slideshow, copy board and separate images/text organized by slide.

Download a ZIP, extract it, and open the PowerPoint in normal editing mode. Select an object and use Ctrl+C / Ctrl+V to copy it into your own presentation. On macOS use Command+C / Command+V.

Published at the project owner’s request so these files can be downloaded through ordinary GitHub links.
