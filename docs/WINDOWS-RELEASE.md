Download **KeyCritter-Windows.exe** below and open it. No GitHub account, installer,
or Node.js is required. This portable app supports Windows 10/11, 64-bit (x64).

1. Quit any older KeyCritter using its tray menu before opening this build.
2. Choose a pet in **My Pets → Character library**.
3. Click **Enable keyboard reactions**. Close the designer to keep the floating pet.
4. Drag the name bar to move it. Use the KeyCritter tray menu to reopen the designer or quit.

The app includes the 500-character library, uploads, blinking frames, and key
reactions. Ordinary typing works offline. AI generation is optional and needs your
own OpenAI API key. Use **Export pet** on the website, then **Import pet** in this desktop app to
transfer your customized design, images, animation frames, and key reactions.
Imports save as a new pet; existing pets remain in your collection.

This development build is unsigned. Windows may display a security warning; only
open a download you trust. Keyboard reactions start paused until you enable them.

The optional **KeyCritter-Windows.zip** also includes instructions, screenshots,
and verification results from testing this exact executable on Windows.
**SHA256SUMS.txt** contains checksums for both public downloads.

The library now includes 500 companions across anime and game series. Browse 24
cards per page, search all characters by name or series, or choose a featured pet
from the preview beneath the typing box. Pose artwork is loaded in small local
batches; the Windows app works offline.

Choose **Anime characters** or **Game characters** beneath the typing box to
filter the preview. **Browse all 500 pets** keeps that category selected in the
full library. Choose a character to make it your active typing companion.

The classified library includes 250 anime characters, 249 game characters, and
laptop buddy. Filter by type, franchise/collection, and series; sort by name or
series and clear all filters at any time. All artwork remains available offline.

Choose **Change background** beneath the room for 22 illustrated scenes. Library
pets get series-based suggestions, and Anime/Game filters let you explore other
worlds. Background choices save with your pet and transfer through export/import.
All backgrounds work offline in the desktop designer.
