KEYCRITTER - WINDOWS DESKTOP PET

For Windows 10/11, 64-bit (x64).

This download is version 1.7.0. The logo and window title show v1.7.0.
Quit any older KeyCritter from the system tray before opening this update.
The included verified-ui.png, verified-ai-ui.png, and verified-animation-ui.png
are screenshots captured while testing this exact portable executable on Windows.

1. Extract the downloaded ZIP to a folder on your computer.
2. Open the KeyCritter-Windows application (.exe). No installer or Node.js is needed.
3. In the designer, click Enable keyboard reactions.
4. Type in another app. Ordinary typing gives your pet a little bounce.
   Space makes it jump, Enter makes it cheer, and Backspace surprises it.
   Change these reactions or add your own in the designer.
5. Drag the little name label beneath the pet to move it.
6. Close the designer to leave the pet on your desktop.

Use the pet's Designer button or the KeyCritter system-tray menu to reopen
settings. The tray icon may be inside Windows' hidden-icons arrow.
Pause reactions from the pet, designer, or tray menu.
Choose Quit KeyCritter in the tray menu to close everything.

Keyboard reactions start paused each time you launch the app.
KeyCritter does not start automatically with Windows.
Typed text is not recorded or transmitted.
Letter and symbol triggers use US keyboard positions.
Your design, reactions, pet position, and pin choice are saved on this computer.

PIN ABOVE OTHER APPS
Leave the Pinned button enabled beneath your pet to keep it above browser tabs
and normal app windows. The same switch is in the designer and tray menu.
You can unpin it at any time; Show pet brings it forward again.

CUSTOM PETS
You can use any character: upload its image as the main pet, then add matching
expressions for reactions. Make more expressions of this character opens the AI
panel with the main image selected as a reference. After generating an expression,
Add as frame adds it to that pose's animation without another AI request.
For blinking, choose Main image and ask to change only the eyes, keeping the
body pose and placement the same. Adjust the sequence in Animate afterward.

Choose Upload in the designer to add a main image and optional reaction poses.
PNG, JPG, and WebP are supported; transparent images work best.
Choose Create with AI to generate a pet or another pose from a prompt.
AI generation needs your own OpenAI API key and API billing, separate from
ChatGPT. Each click requests one image. Preview the result before applying it.
Your typing is never sent to the AI. A reference image is sent only if selected.
Keys are session-only unless you choose encrypted storage on this computer.

BLINKING AND FRAME ANIMATIONS
To use the included laptop character, choose:
Animate > Idle / blink > Use laptop buddy > Save pet.
Her frames and slow-blink timing are included. No API key, payment, Internet
connection, or manual image upload is needed to use this preset.
You can adjust the frame durations afterward. It uses a 400 ms closed-eye hold.

To add your own frames:
1. Choose Animate in the designer, then Idle / blink.
2. Click Add frames and select your images (up to 12 per animation).
   For blinking: open eyes, half-closed, closed, open eyes.
3. Use the numbered frames' arrows to change the order. Adjust each duration
   in milliseconds, or choose Use blink timing for 100 ms frames and a 3 s pause.
4. Leave Repeat animation enabled for blinking. During a pause, frame 1 is shown.
   Use images with matching canvas sizes to prevent the pet from shifting around.
5. Select another pose, such as Cheer, to add a sequence for a key reaction.
   Assign that action to a key in Key reactions, then try it.
6. Choose Save pet. Idle animations play on the floating pet automatically.
   No AI connection is needed for uploaded animations.

Stop preview pauses only the small editor preview. Use this animation on my pet
turns the actual animation on or off. Windows reduced-motion settings use a still
frame. Replacing a pose through Upload or AI turns off that pose's animation;
you can enable its saved frames again in Animate.

MOVEMENT STRENGTH AND POSITION
Use Movement strength below Size to control shaking and bouncing. Try 25% for
gentle movement or 0% to keep the body still while blinking frames keep playing.
Reset restores 100%. The setting is saved with each pet.
Click and hold the floating pet's name bar marked Drag to move, then drag it
to another place on the screen. Your new position is saved for the next launch.
Dragging follows the actual mouse position. Transparent padding may go off-screen;
when you release, the name bar is kept reachable so you can move the pet again.

This is an unsigned development build. Its behavior in your Windows desktop
session still needs to be checked, even when the Windows build succeeds.

BRING YOUR WEBSITE PET WITH YOU
On the website, choose your pet, then click Export pet under Take this pet with you.
In this desktop app, click Import pet and select the .keycritter.json file.
Images, animations, movement strength, and key reactions transfer together.
The import saves a new pet without replacing the rest of your collection.
You can also export from the desktop app and import into the website.

BROWSE THE CLASSIFIED LIBRARY
Use My Pets or Browse all 500 pets below the typing box.
Choose Anime or Game, then select a franchise/collection and series.
Use search and sorting together, or Clear filters to see the entire collection.
